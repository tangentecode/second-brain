- Stufenmodell: 
	- Auf jeder Stufe einer Tonleiter Terzschichtung
	- Ergibt Dur/Moll/(verminderte) Akkorde
	- Akkordbrechungen: Töne eines Akkordes hintereinander 
	- Diese Akkorde haben Nummern/Bezeichnungen
	- Siehe Stufenmodell PDF

- Klassik vs. Jazz:

| Klassik                   | Jazz                      |
| ------------------------- | ------------------------- |
| Dreiklänge                | Vierklänge (7th Coords)   |
| I-IV-V Alkordverbindungen | ii-V-I Akkordverbindungen |

  

- ii-V-I: 

| Name              | Effekt            | Akkord     |
| ----------------- | ----------------- | ---------- |
| Subdominante (ii) | Vorbereitung      | m7 (D-7)   |
| Dominante (V)     | maximale Spannung | 7 (G7)     |
| Tonika (I)        | Auflösung (Ruhe)  | maj7 (C△7) |

  

- Guide Tones
	- Terz (3) und Septime (7) eines Akkords. 
	- Für jeden Akkord so wählen das diese möglichst nah zusammen liegen
- Jazz: Bewegung der Terz und Septime. Alles andere ist Dekoration.
